# MorphoBr

[![CI](https://github.com/LR-POR/MorphoBr/actions/workflows/ci.yml/badge.svg)](https://github.com/LR-POR/MorphoBr/actions/workflows/ci.yml)
[![License: Apache 2.0](https://img.shields.io/github/license/LR-POR/MorphoBr.svg)](LICENSE)
[![Issues](https://img.shields.io/github/issues/LR-POR/MorphoBr.svg)](https://github.com/LR-POR/MorphoBr/issues)

**Resources for the morphological analysis of Portuguese.** MorphoBr is a
large-coverage lexicon of Portuguese word forms and their analyses (lemma,
part of speech and inflectional features), which compiles into a single
finite-state transducer for morphological analysis and generation.

Authors: Leonel F. de Alencar, Alexandre Rademaker, Bruno Cuconato.

## Contents

| Class | Lemmas | Pairs (form, analysis) |
|---|---:|---:|
| Nouns | 83,703 | 537,572 |
| Adjectives | 55,468 | 543,778 |
| Verbs | 28,095 | 2,052,130 |
| Adverbs | 21,146 | 21,181 |
| Verbs with clitics | 14,274 | 7,705,419 |
| **Total** | | **10,860,080** |

Each entry pairs a form with an analysis:

```
casinhas      casa+N+DIM+F+PL
fique         ficar+V+SBJR+1+SG
comprei-o     comprar+V.ele.ACC.3.M.SG+PRF+1+SG
```

See [`TAGSET.org`](TAGSET.org) for the tags.

## Quick start

```bash
FOMA=/path/to/foma ./compile.sh          # builds morphobr.bin (see Building)
echo "fortinho" | flookup -i morphobr.bin
```

```
fortinho	forte+N+DIM+M+SG
fortinho	forte+A+DIM+M+SG
```

`flookup -i` analyzes a form; `flookup` (without `-i`) generates the forms of
an analysis.

## Repository layout

| Path | Contents |
|---|---|
| `nouns/`, `adjectives/`, `verbs/`, `adverbs/`, `clitics/` | Full-form lists (`*.dict`): one `form<TAB>analysis` per line. |
| `rules/` | Finite-state inflection rules for verbs (`verbs.lexc`, `orthography.foma`, `classes.tsv`) and the diminutive grammar (`dim/`). |
| `lexicon/` | Lemmas whose forms are generated by the rules: `verbs/<model>.tsv`, `dim/nouns.tsv`, `dim/adjectives.tsv`. |
| `compile.sh`, `compile.foma` | Build of the transducer `morphobr.bin`. |
| `code/` | Converter from `*.dict` to Foma's spaced-text format (Haskell). |
| `tools/` | Maintenance scripts (see [Tools](#tools)). |
| `maps/` | Tag mappings to other formats. |

The `*.dict` files are split by the first letter (without accents) of the
lemma, and their lines are kept in a **canonical order**: sorted by analysis
and then by form, comparing bytes (`LC_ALL=C`), without repeated lines, so all
entries of a lemma stay together. After editing a dictionary, run
`tools/canonicalize.sh` (or `tools/canonicalize.sh --check` to only check).

## Conventions

- **Uniform and invariable words.** Words with the same form in both genders
  have no gender tag (`inteligente+A+SG`, `dentista+N+SG`); invariable words
  have no number tag (`lápis+N+M`, `simples+A`). When the masculine and the
  feminine of a form coincide, there is a single analysis without gender
  (`artistinha artista+N+DIM+SG`).
- **Brazilian and European Portuguese.** Forms of both varieties are included,
  e.g. both forms of the first person plural of the preterite of verbs in *-ar*
  (*falamos*, *falámos*).
- **Spelling before the 1990 Orthographic Agreement.** Old forms are kept
  alongside the current ones (*freqüentar*, *argüir*), since they are useful
  for older texts ([#93](https://github.com/LR-POR/MorphoBr/issues/93)).
- **Not included as nouns:** symbols, units and abbreviations (*kg*, *Ca*, *sr*),
  which may come back with a specific annotation
  ([#71](https://github.com/LR-POR/MorphoBr/issues/71)). Foreign words and
  neologisms not registered in the reference vocabularies are discussed in
  [#148](https://github.com/LR-POR/MorphoBr/issues/148).
- **References.** Entries are checked against the
  [Portal da Língua Portuguesa](https://www.portaldalinguaportuguesa.org/)
  and other reference dictionaries (Priberam, Aulete, Houaiss).

## Inflection rules and full-form lists

Regular paradigms are generated by finite-state rules instead of being listed
form by form ([#143](https://github.com/LR-POR/MorphoBr/issues/143)). The
compiled transducer is the **union** of the rules and the full-form lists.

### Verbs

- `rules/verbs.lexc` defines the inflection classes, each named after a model
  verb: `ABAFAR` (regular verbs in *-ar*), `PASSEAR` (*-ear*), `BATER` (*-er*),
  `PARTIR` (*-ir*), and classes for verbs that share an ending, such as
  `ATRIBUIR` (*-uir*), `ADERIR` (*-erir*: *adiro*), `CONDUZIR`, `FAZER` or
  `CONTER`.
- `rules/orthography.foma` defines the spelling alternations (*ficar* →
  *fique*, *pagar* → *pague*, *abraçar* → *abrace*; *conhecer* → *conheço*,
  *proteger* → *protejo*, *distinguir* → *distingo*).
- `rules/classes.tsv` registers, for each class, the model verb, the ending
  removed to get the stem (*aderir* → *ad-*, so *preferir* → *pref-* + *-iro*)
  and the suffix of the lemmas it applies to. A new class is created from the
  forms of its model with `tools/make-class.py MODEL ENDING`.
- `lexicon/verbs/<model>.tsv` lists, one per line, the lemmas that inflect like
  the model verb.

### Diminutives

Diminutives in *-inho*/*-zinho* (also of augmentatives) of nouns and adjectives
are generated by the finite-state grammar of Leonel de Alencar in `rules/dim/`,
from the base forms (without `+DIM`) in the `*.dict` files, for the lemmas
listed in `lexicon/dim/` ([#149](https://github.com/LR-POR/MorphoBr/issues/149)).
`tools/dim.py generate` writes the generated pairs.

### What stays in the `*.dict` files

Irregular verbs, variants, homographs, the base forms of nouns and adjectives,
diminutives not generated by the grammar, and words of other classes.

### The criterion: rules never change the lexicon

A lemma is moved to the rules only if they generate **nothing that was not
already in the `*.dict` files**; then exactly the generated pairs are removed
from them. `tools/rules-migrate.py` (verbs) and `tools/dim.py migrate`
(diminutives) do this; they can be run again after a new class is added, and a
new class never changes the lexicon, even if its model is badly chosen.

`tools/expand.sh` writes the complete full-form list (rules + `*.dict`, in
canonical order). To check that a change preserves the lexicon, run it before
and after the change and compare the outputs:

```bash
tools/expand.sh > before.txt      # on the original revision
tools/expand.sh > after.txt       # with the change
cmp before.txt after.txt
```

## Building

`compile.sh` builds the converter in `code/`, converts the dictionaries to
Foma's spaced-text format, generates the verbs and diminutives of the rules and
runs `compile.foma`, producing `morphobr.bin`. The build takes about 3 minutes
and needs about 5 GB of memory.

Requirements:

1. [stack](https://docs.haskellstack.org), to build the converter in `code/`.
2. Python 3, to generate the diminutives (`tools/dim.py`).
3. A **Foma that can read the large lexicon.** Foma 0.10.0 (e.g. from Homebrew)
   aborts with `Stack full!` because its internal stacks have a fixed size
   ([mhulden/foma#130](https://github.com/mhulden/foma/issues/130)). Use Foma
   with dynamic stacks ([mhulden/foma#176](https://github.com/mhulden/foma/pull/176)),
   or change `MAX_STACK` in `foma/int_stack.c` to at least 9097152 and compile
   Foma. To use a Foma that is not in the `PATH`, set `FOMA`:

   ```bash
   FOMA=~/foma/foma/build/foma ./compile.sh
   ```

The dictionary files must use LF line endings (enforced by `.gitattributes`):
CR characters break the compilation.

## Continuous integration

Each push to `master` and each pull request runs
[`.github/workflows/ci.yml`](.github/workflows/ci.yml):

- checks the canonical order of the dictionaries and lemma lists;
- compiles the whole lexicon with `compile.sh` (using a Foma with dynamic
  stacks) and checks some reference analyses;
- publishes `morphobr.bin` as an artifact of the run;
- in pull requests, compares the complete full-form list of the base and of the
  pull request and writes in the summary of the run how many pairs were removed
  and added. A change of representation (e.g. moving lemmas to the rules) must
  show none.

## Tools

| Script | Purpose |
|---|---|
| `tools/canonicalize.sh` | Sorts the dictionaries and lemma lists in the canonical order (`--check` only checks). |
| `tools/expand.sh` | Writes the complete full-form list (rules + `*.dict`). |
| `tools/lexicon-to-lexc.sh` | Generates the stem lexicon of the verb rules from `lexicon/verbs/`. |
| `tools/make-class.py` | Creates a verb inflection class from the forms of its model verb. |
| `tools/rules-migrate.py` | Moves verbs to the rules (strategy above). |
| `tools/dim.py` | Generates the diminutives (`generate`) and moves lemmas to the rules (`migrate`). |
| `tools/CheckUnification.py` | Checks the lexicon against a treebank in CoNLL-U format (e.g. Bosque). |

The remaining code in `tools/` was used to import and convert the source
dictionaries (DELAF-PB, FreeLing) and is kept for reference; its review is
discussed in [#143](https://github.com/LR-POR/MorphoBr/issues/143).

## Sources

Unless otherwise stated, the resources are derived from the dictionaries of:

- the [Unitex-PB project](http://www.nilc.icmc.usp.br/nilc/projects/unitex-pb/web/dicionarios.html);
- the [FreeLing Portuguese data](https://github.com/TALP-UPC/FreeLing/tree/master/data/pt/dictionary/entries),
  itself derived from [LABEL-LEX](http://label.ist.utl.pt/pt/labellex_pt.php),
  using unpublished data from *Garcia, Marcos et al.*, available from commit
  [a0ebdbc](https://github.com/LR-POR/MorphoBr/tree/a0ebdbc496035642277788cecb156a169bae309b/tmp).

The derived nouns in *-idade*, adjectives in *-vel*, adverbs in *-mente* and
verbs in *-izar* were produced by finite-state models of these word-formation
processes developed in:

- SILVA, H. L. B. *Expansão do MorphoBr através da modelagem computacional de
  processos de formação de palavras em português*. Dissertação (Mestrado em
  Linguística), Universidade Federal do Ceará, Fortaleza, 2019. Data and
  transducers: <https://github.com/heliolbs/MorphoBrExpansion>
